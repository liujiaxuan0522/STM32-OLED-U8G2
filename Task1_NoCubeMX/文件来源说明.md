# 任务一：每个 Group 的文件从哪来（按你电脑的实际路径）

你电脑上的 Keil STM32F1 器件包在：

```text
E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0
```

CMSIS Core 头文件在：

```text
E:\Keil\packs\ARM\CMSIS\5.9.0\CMSIS\Core\Include
```

任务一用到的文件分两类：

1. **ST 官方 SPL/DFP 文件**：Startup、CMSIS、StdPeriph_Driver；
2. **我们写的应用代码**：`Task1_NoCubeMX\User` 下的 6 个 `.c`。

## 1. Startup Group

| 文件 | 你电脑上的路径 |
| --- | --- |
| `startup_stm32f10x_md.s` | `E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\Source\ARM\startup_stm32f10x_md.s` |

C8T6 是中等容量，必须用 `md`。

## 2. CMSIS Group

| 文件 | 你电脑上的路径 |
| --- | --- |
| `system_stm32f10x.c` | `E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\Source\system_stm32f10x.c` |

头文件不加入 Group，放到 Include Paths：

```text
E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\Include
E:\Keil\packs\ARM\CMSIS\5.9.0\CMSIS\Core\Include
```

> 你的 CMSIS 5 里没有 `core_cm3.c`，只有 `core_cm3.h`，所以不需要加 `core_cm3.c`。

## 3. StdPeriph_Driver Group

| 文件 | 你电脑上的路径 |
| --- | --- |
| `stm32f10x_gpio.c` | `E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\StdPeriph_Driver\src\stm32f10x_gpio.c` |
| `stm32f10x_rcc.c` | `E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\StdPeriph_Driver\src\stm32f10x_rcc.c` |

头文件 Include Path：

```text
E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\StdPeriph_Driver\inc
```

任务一用软件 I2C，不需要 `stm32f10x_i2c.c`。

## 4. User Group

这 6 个 `.c` 是我们写的，位置：

```text
STM32_OLED_U8G2\Task1_NoCubeMX\User\
```

| 文件 | 作用 |
| --- | --- |
| `main.c` | 主程序 |
| `soft_i2c.c` | 软件 I2C |
| `oled.c` | SSD1306 驱动、显存、字符/汉字、滚动 |
| `font_ascii.c` | 8×16 ASCII 点阵 |
| `font_cn.c` | 16×16 汉字点阵 |
| `delay.c` | 延时 |

头文件：

```text
User\soft_i2c.h
User\oled.h
User\font_ascii.h
User\font_cn.h
User\delay.h
User\stm32f10x_conf.h
```

`User` 目录加入 Include Paths。

## 5. stm32f10x_conf.h

模板位置：

```text
E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\StdPeriph_Driver\templates\stm32f10x_conf.h
```

但本工程 `User` 里已经有一个最小版本：

```text
Task1_NoCubeMX\User\stm32f10x_conf.h
```

二选一，建议用 `User` 里的。

## 6. 最终对应关系

```text
Target 1
├─ Startup
│  └─ startup_stm32f10x_md.s          ← E:\Keil\...\Device\Source\ARM\
├─ CMSIS
│  └─ system_stm32f10x.c               ← E:\Keil\...\Device\Source\
├─ StdPeriph_Driver
│  ├─ stm32f10x_gpio.c                 ← E:\Keil\...\StdPeriph_Driver\src\
│  └─ stm32f10x_rcc.c                  ← E:\Keil\...\StdPeriph_Driver\src\
└─ User
   ├─ main.c                           ← 我们写的
   ├─ soft_i2c.c                       ← 我们写的
   ├─ oled.c                           ← 我们写的
   ├─ font_ascii.c                     ← tools/gen_font.py 生成
   ├─ font_cn.c                        ← tools/gen_font.py 生成
   └─ delay.c                          ← 我们写的
```

## 7. 一句话总结

- **Startup / CMSIS / StdPeriph_Driver**：从 `E:\Keil\packs\Keil\STM32F1xx_DFP\2.2.0\Device\` 里找；
- **CMSIS Core 头文件**：从 `E:\Keil\packs\ARM\CMSIS\5.9.0\CMSIS\Core\Include` 找；
- **User**：从 `STM32_OLED_U8G2\Task1_NoCubeMX\User` 找；
- **CubeMX/HAL/U8g2**：是任务三的，不要加到任务一。
