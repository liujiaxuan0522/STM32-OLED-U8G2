# 任务三：CubeMX + HAL + U8g2 详细操作

> 任务三使用 **STM32CubeMX + Keil MDK + HAL 库 + U8g2**。  
> 任务一（不用 CubeMX，SPL + 软件 I2C）在 `../Task1_NoCubeMX/`。  
> 本次没有 AHT20，温湿度功能不做。

## 1. 准备

需要：

- STM32F103C8T6 开发板；
- 0.96 寸 SSD1306 I2C OLED，128×64；
- ST-Link 或 DAP 下载器；
- STM32CubeMX；
- Keil MDK5；
- U8g2 源码：<https://github.com/olikraus/u8g2>。

接线：

| OLED | STM32F103 |
| --- | --- |
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 / I2C1_SCL |
| SDA | PB7 / I2C1_SDA |

OLED 地址一般是 `0x3C`，8 位写地址 `0x78`。

## 2. CubeMX 新建工程

1. 打开 STM32CubeMX；
2. `File → New Project`；
3. 搜索并选择：

```text
STM32F103C8Tx
```

4. 点 `Start Project`。

## 3. 配置 SYS

左侧：

```text
System Core → SYS
```

- `Debug` 选：

```text
Serial Wire
```

否则下载一次后可能锁住 SWD。

## 4. 配置 RCC

```text
System Core → RCC
```

- `High Speed Clock (HSE)` 选：

```text
Crystal/Ceramic Resonator
```

## 5. 配置 I2C1

```text
Connectivity → I2C1
```

- `I2C` 选 `I2C`；
- `Speed Mode` 选 `Fast Mode`；
- `Clock Speed` 填：

```text
400000
```

引脚应该是：

```text
PB6 → I2C1_SCL
PB7 → I2C1_SDA
```

如果引脚不是 PB6/PB7，在芯片引脚图上点 PB6/PB7 重新映射。

## 6. 配置时钟

打开 `Clock Configuration`：

- `HSE` 选 8 MHz；
- `PLL Source` 选 HSE；
- `PLLMul` 选 `×9`；
- `SYSCLK` 选 PLLCLK，应为 72 MHz；
- `APB1 Prescaler` 选 `/2`，APB1 为 36 MHz；
- I2C1 时钟来自 APB1，36 MHz 下 400 kHz 没问题。

## 7. 生成 Keil 工程

`Project Manager`：

### Project

- `Project Name`：例如 `OLED_U8g2`；
- `Project Location`：例如：

```text
F:\deepseek-harness-workspace\STM32_OLED_U8G2\Task3_CubeMX_U8g2\MDK-ARM
```

- `Toolchain / IDE`：

```text
MDK-ARM
```

- `Min Version`：V5。

### Code Generator

勾选：

```text
Copy only the necessary library files
Generate peripheral initialization as a pair of .c/.h files
```

然后点右上角：

```text
GENERATE CODE
```

生成后打开：

```text
MDK-ARM\OLED_U8g2.uvprojx
```

先点一次 `Build`，确认 CubeMX 生成的空工程能编译通过。

## 8. 添加 U8g2 源码

1. 下载 U8g2；
2. 解压后找到：

```text
u8g2-master\csrc
```

3. 把整个 `csrc` 复制到 CubeMX 工程目录，例如：

```text
OLED_U8g2\Middlewares\u8g2\csrc
```

4. 在 Keil 左侧 `Project` 窗口右键 `Target 1` → `Manage Project Items`；
5. 新建 Group：

```text
U8g2
User
```

6. 右键 `U8g2` → `Add Existing Files to Group 'U8g2'`；
7. 进入：

```text
Middlewares\u8g2\csrc
```

把里面的 `.c` 文件全部加入 `U8g2` Group。

> 最省事的方法就是全加，避免 `u8g2_Setup_ssd1306...`、`u8x8_d_ssd1306...` 未定义。  
> 如果嫌多，至少保留：`u8g2_*.c`、`u8x8_*.c`、`u8g2_fonts.c`。

## 9. 添加本任务的源码

把本目录：

```text
Task3_CubeMX_U8g2\Core\Inc
```

里的文件复制到 CubeMX 工程的：

```text
Core\Inc
```

把：

```text
Task3_CubeMX_U8g2\Core\Src
```

里的文件复制到：

```text
Core\Src
```

包括：

```text
Core\Inc\app.h
Core\Inc\avatar.h
Core\Inc\oled_app.h
Core\Inc\u8g2_hal.h

Core\Src\main_app.c
Core\Src\oled_app.c
Core\Src\u8g2_hal.c
```

然后在 Keil 的 `User` Group 里加入这 3 个 `.c`：

```text
main_app.c
oled_app.c
u8g2_hal.c
```

## 10. 加 Include Paths

`Options for Target`（魔术棒）→ `C/C++` → `Include Paths`：

```text
Core\Inc
Middlewares\u8g2\csrc
```

如果 U8g2 放在别的位置，按实际路径改。

## 11. C99

`Options for Target → C/C++`：

勾选：

```text
C99 Mode
```

如果编译提示：

```text
u8g2_font_wqy12_t_chinese1 undefined
```

在 `C/C++ → Define` 加：

```text
U8G2_USE_LARGE_FONTS
```

并把 `u8g2_fonts.c` 加入工程。

## 12. 修改 main.c

打开 CubeMX 生成的：

```text
Core\Src\main.c
```

### 12.1 包含头文件

在：

```c
/* USER CODE BEGIN Includes */
```

中加入：

```c
#include "app.h"
```

### 12.2 初始化

在 `MX_I2C1_Init();` 之后，找到：

```c
/* USER CODE BEGIN 2 */
```

加入：

```c
App_Init();
```

### 12.3 主循环

在：

```c
while (1)
{
    /* USER CODE BEGIN 3 */
}
```

中加入：

```c
App_Loop();
```

完整位置示例：

```c
/* USER CODE BEGIN 2 */
App_Init();
/* USER CODE END 2 */

while (1)
{
    /* USER CODE BEGIN 3 */
    App_Loop();
    /* USER CODE END 3 */
}
```

> `App_Loop()` 里面有滚动和动画，会一直循环，不要再在 while 里加别的阻塞代码。

## 13. 修改姓名/学号

打开：

```text
Core\Inc\oled_app.h
```

改成：

```c
#define STUDENT_NAME "刘佳烜"
#define STUDENT_ID   "632407030115"
```

如果中文姓名显示空白，说明 `u8g2_font_wqy12_t_chinese1` 不包含该汉字，需要：

- 换 `u8g2_font_wqy12_t_gb2312`；或
- 用 `bdfconv` 生成自定义字库；或
- 先用拼音/昵称。

## 14. 检查 U8g2 初始化

`Core\Src\u8g2_hal.c` 中：

```c
#define OLED_I2C_ADDR 0x78
```

这是 0x3C 的 8 位写地址。

如果模块地址是 0x3D，改成：

```c
#define OLED_I2C_ADDR 0x7A
```

初始化函数：

```c
u8g2_Setup_ssd1306_i2c_128x64_noname_f(
    &u8g2,
    U8G2_R0,
    u8x8_byte_hw_i2c,
    u8x8_gpio_and_delay_cb);
```

## 15. 运行效果

`App_Loop()` 会按顺序执行：

1. 显示姓名、学号；
2. 显示系统信息；
3. 左右滚动长字符串；
4. 上下滚动多行文字；
5. 运行 U8g2 demo：边框、圆、线、矩形、文字；
6. 32×32 头像动画。

## 16. 替换头像

`Core\Inc\avatar.h` 里是 32×32 XBM 笑脸，可以替换成自己的头像/校徽。

步骤：

1. 准备 32×32 黑白图片；
2. 用 image2cpp 或类似工具转成 XBM；
3. 勾选 LSB / 横向 / 1 位；
4. 把数组替换 `avatar_bits[128]`；
5. 重新编译。

## 17. 常见错误

### `u8g2.h: No such file`

Include Paths 少了：

```text
Middlewares\u8g2\csrc
```

### `u8g2_Setup_ssd1306_i2c_128x64_noname_f` 未定义

U8g2 的 `.c` 文件没有全部加入，至少检查：

```text
u8g2_d_setup.c
u8x8_d_ssd1306_128x64_noname.c
```

### `hi2c1` 未定义

`u8g2_hal.c` 里要包含：

```c
#include "i2c.h"
```

CubeMX 生成的 `i2c.h` 里才有 `extern I2C_HandleTypeDef hi2c1;`。

### OLED 不亮

- 地址 0x3C/0x3D；
- SCL/SDA 接反；
- 没有上拉；
- 供电不是 3.3V；
- `U8g2_Init()` 没调用；
- `u8g2_SetPowerSave(&u8g2, 0)` 没调用。

### 中文乱码/空白

- 源文件不是 UTF-8；
- 字库不包含该汉字；
- 没有 `U8G2_USE_LARGE_FONTS`；
- `u8g2_fonts.c` 没加入工程。

### Flash 不够

C8T6 只有 64 KB：

- 换 CBT6（128 KB）；
- 用 bdfconv 生成只含作业字符的子集；
- 只保留必要字体。

## 18. Keil 虚拟逻辑分析仪

硬件 I2C 的 SCL/SDA 由 I2C 外设驱动，Keil Logic Analyzer 通常不能完整还原 I2C 协议，最多看到引脚变化。

如果要观察完整 I2C 时序，建议：

- 外接 Saleae Logic 16；
- 示波器双通道；
- sigrok/PulseView；
- 或临时用软件 I2C + GPIO 翻转。

详细说明见任务一的 `Keil_Add_Files.md` 和 README。
